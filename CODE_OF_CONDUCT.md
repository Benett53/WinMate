# Code of Conduct

WinMate follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and focus on the problem rather than the person.
Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer via a
[GitHub security advisory](https://github.com/Benett53/WinMate/security/advisories/new) (it is private) or by
contacting [@Benett53](https://github.com/Benett53). Reports are handled confidentially.
